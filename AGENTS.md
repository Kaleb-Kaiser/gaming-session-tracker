# AGENTS.md

## Project Overview
This project is a Gaming Session Tracker web application designed to run entirely on GitHub Pages using only HTML, CSS, and JavaScript. The application will allow users to log gaming sessions, moods, hours played, and notes while storing all information locally in the browser using Local Storage.

## Goals
- Create a simple and responsive web app
- Allow users to add, edit, and delete gaming sessions
- Store all data locally in the browser
- Display gaming history and mood trends
- Maintain compatibility with GitHub Pages hosting

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage API

## Core Features
1. Add gaming sessions
2. Track hours played
3. Select mood icons
4. Add optional notes
5. View saved sessions
6. Delete sessions
7. Basic statistics display
8. Responsive mobile-friendly design

## User Interface Requirements
- Dark gaming-themed interface
- Clean card-based layout
- Responsive design for desktop and mobile
- Easy navigation
- Visual mood indicators

## File Structure
- index.html
- style.css
- script.js
- AGENTS.md
- ARCHITECTURE.md

## Storage Requirements
- Use Local Storage for saving all session data
- Save data automatically after changes
- Load data automatically on startup

## Development Notes
- Keep the project beginner-friendly
- Avoid external frameworks
- Use comments to explain major functions
- Prioritize readability and maintainability

## GitHub Pages Compatibility
- All functionality must work client-side only
- No backend or database
- No Node.js dependencies
